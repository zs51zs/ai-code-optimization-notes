## 当前研究思路

以 **可信评价** 为基础，研究运行时证据、反馈迭代与候选搜索对代码性能优化的作用。计划通过统一任务与可比预算的对照/消融实验，检验真实性能收益及正确性风险，而非仅靠单次运行时间或论文报告的数字。

- 文档标注的论文结论来自对应论文或其开源代码；未复现内容应明确标识。
