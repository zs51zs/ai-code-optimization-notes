# 开题积累：背景、相关工作、研究问题与证据

> 此文件为动态材料库；不等于已经完成的开题报告。

## 1. 研究背景（可用材料）
大型模型已能解决大量软件功能型任务，但性能优化要求在保持语义和行为正确的前提下减少资源开销。仓库级任务还涉及跨文件理解、复杂构建环境以及真实性能反馈。已有工作 SWE-Perf 构建真实仓库性能优化基准，说明这类任务可以评估，但所评估 Agent 与专家尚有差距。

**证据**：He et al., SWE-Perf, ICML 2026, https://proceedings.mlr.press/v306/he26y.html

## 2. 相关工作分类（持续补充）
- 评测：SWE-Perf、SWE-fficiency、FormulaCode。
- 性能反馈：PerfAgent、Codeflash。
- 进化搜索：AlphaEvolve、ShinkaEvolve。
- Agent 底座：OpenHands SDK、mini-swe-agent。
- 测量可信性：统计筛选、覆盖相关性、隐藏测试、reward-hacking 防护。

## 3. 候选科学问题（非已证实创新）
- Q1：哪些性能反馈表达使 Agent 更有效定位瓶颈？
- Q2：怎样在有限成本下选择不同候选代码修改？
- Q3：将通用优化 Agent 扩展到 C++/并行程序时，哪些边界条件导致性能判断失效？

## 4. 实验路线草案
- 第一层：可控的 Python/C++ 局部程序验证；
- 第二层：真实仓库工作负载、已知专家 Patch 的测试；
- 第三层：ParaLedger 等多节点程序作为复杂扩展案例；
- 对照：无 Profiling、只提供运行时间、结构化 Profiler 反馈；单路径与多候选搜索。
