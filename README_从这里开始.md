## 状态定义
- `L0 待核查`：已有线索，尚未核实原文。
- `L1 导读`：确认论文身份、研究目标、核心流程及来源，尚未全文精读。
- `L2 精读`：阅读关键方法、实验和局限，形成可核对的笔记。
- `L3 复现`：对关键源码运行/验证，有日志和仓库 commit 记录。

当前内容绝不表示本地复现成功；没有仓库运行结果就明确写“未复现”。

## 同步方式（建议）
将整个文件夹存入个人 Git 仓库或研究项目的 `research/reading-notes/` 路径，使用 Git commit 跟踪变更。在 Codex 开发仓库中可先放一个只读副本或者链接，不要混入生产代码。与 Research Agent 的大范围文献综述合并时以 DOI/arXiv ID 去重。
